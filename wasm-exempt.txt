# Programs the playground runs on .NET rather than compiled to WebAssembly
# until something is fixed or added, one a line: the program's id in the
# index, then what it needs. CI builds and runs every program the
# playground can run for wasm, unless this file or wasm-never.txt lists
# it, against the compiler, ghul-runtime and ghul-raster this repository
# pins, and the index marks each of those `wasm`. A program with a
# playground-unsupported file is not run in the playground at all and is
# not listed here.
#
# Remove a line when its program passes on wasm; CI then holds it there.
